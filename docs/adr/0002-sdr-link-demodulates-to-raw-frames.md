# SDR link demodulates to Raw frames at the edge, natively on Android

An SDR link delivers IQ samples, not lines. Its demodulator turns them into `+SS<hex>;` Raw frames right next to the driver and hands them to the same line handler a Serial link and the Broker feed use, so decode, CPR, the aircraft store and RSSI stay one code path for every Input source. In the browser the demodulator runs in a Web Worker on WebUSB samples. In the Capacitor app the Android WebView has no WebUSB, and 2 Msps of IQ (4 MB/s) is far too much to push through the Capacitor bridge, so the driver and the demodulator live in a native Kotlin plugin that emits only Raw frames. The cost is two demodulator implementations (TypeScript and Kotlin) that must be kept in sync, checked by a shared IQ fixture.
